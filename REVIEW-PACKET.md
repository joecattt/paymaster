## Explicit limitations (also in SECURITY.md)
- Governs only routed paths; agents holding raw provider credentials bypass it entirely.
- No universal enforcement — the gate is shadow-mode (observes, reports, blocks nothing).
- Completeness is provable only in aggregate (no provider enumeration APIs exist).
- The git anchor proves repository continuity, not external witness.
- Provider-reported cost is authoritative for the reported charge at time observed;
  subject to later correction. "Reconciled" is not "economically final."
- Would-DENY counts are never savings claims.
- CLI commands `coverage` and `prove-nonzero` (dry-run included) perform a
  read-only provider API query and require an API key; the test suite does not.
